TurmaLina UI Kit

Documentação prática dos estilos do projeto turmaLina, organizada em classes utilitárias e componentes com sintaxe familiar ao Bootstrap. Abra o SCSS junto desta página para usar no Angular.

InstalaçãoCoresBotõesCardsBadges e chipsAlertasFormuláriosProgressoNavegaçãoTabelasLayoutTema corporativo

Comece por aqui

Copie turmalina-ui-kit.scss para a pasta de estilos do Angular. Em src/styles.scss, importe o arquivo:

@use './styles/turmalina-ui-kit';

Depois, use as classes no template:

<button type="button" class="btn btn-primary">Salvar</button>

<div class="card">
  <div class="card-body">
    <h3 class="card-title">Título do card</h3>
    <p class="card-text">Conteúdo do cartão.</p>
  </div>
</div>

A documentação é uma referência visual. O arquivo SCSS é a fonte real das classes; comportamentos como abrir modal ou alternar abas precisam ser implementados no Angular.

Barra de progresso

A largura é definida pela variável CSS --progress.

Progresso da missão72%
<div class="progress">
  <div class="progress-bar" style="--progress: 72%"></div>
</div>

<div class="progress progress-lg">
  <div class="progress-bar progress-bar-success"
       style="--progress: 100%"></div>
</div>

No SCSS, a classe .progress-bar lê --progress como largura. Para usar o HTML acima, mantenha a classe progress-bar no elemento interno.

Tema corporativo

O projeto original possui uma aparência corporativa alternativa. No kit, use o atributo data-tl-theme="corporate" em um wrapper ou no elemento raiz.

<div data-tl-theme="corporate">
  <button class="btn btn-primary">Ação corporativa</button>
  <div class="card">
    <div class="card-body">Card em tema corporativo</div>
  </div>
</div>

O tema troca tokens de cor, tipografia e reduz os efeitos de relevo para um visual mais sóbrio.
